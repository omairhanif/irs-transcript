# IRS Transcript Code 971 Explained: Notices, Updates, and Next Steps

Seeing **IRS Transcript Code 971** on your tax account transcript can raise questions. You might wonder whether the IRS sent you a notice, changed your tax return, or recorded an action that could affect your refund.

Code 971 is used by the IRS to record different actions on a taxpayer's account. It is often linked with notices and letters, but it can also record other activity, such as an amended return being sent for processing.

The key thing to remember is that Code 971 has more than one meaning. Its meaning depends on the action code or the transaction description.

This guide explains what IRS Code 971 is, why it may appear, how to find out what action it represents, and what to do if it shows up on your transcript.

## What Does IRS Transcript Code 971 Mean?

IRS Transaction Code 971 records actions or information linked to a taxpayer's account.

According to the IRS Internal Revenue Manual, Code 971 can be used to link taxpayer numbers or tax periods, find information about an account, or show where a taxpayer's claim was sent. The exact action is indicated by a three-digit Action Code (AC).

For taxpayers, Code 971 may be related to:

- A notice or letter sent by the IRS
- An amended tax return sent for processing
- A refund check reported as not received
- An update to your account or another administrative action
- Processing, collection, or review activity

For example:

| Transaction | Date | Amount |
| --- | --- | ---: |
| Notice issued (971) | March 18, 2026 | $0.00 |

This example shows a notice-related action recorded on an account. Check your IRS Online Account and physical mail for the notice.

**Important:** Code 971 by itself does not tell you what the IRS needs you to do. Review the transaction description, action code if available, and any related IRS correspondence.

## Why Does Code 971 Show Up on Your IRS Transcript?

There are several reasons Code 971 might appear. The specific reason depends on the action recorded on your account.

### 1. The IRS sent a notice or letter

One common description associated with Code 971 is “Notice Issued.” This means the IRS recorded that a notice or letter was sent about your account.

The notice may explain a change to your return, request information, provide an update, or describe another account action. For example, it might say:

- Your tax return needs review.
- A calculation on your return changed.
- More information is needed.
- Your refund is delayed.
- You owe money.

The notice—not Code 971 alone—explains the actual reason and any action you need to take.

### 2. Your amended tax return was sent for processing

Code 971 can also appear when an amended return or claim is sent to another IRS department for processing. For example, Action Code 010 is used when an amended return or claim is sent to Accounts Management. Other action codes may indicate that it was sent to Examination or Collection.

If you recently filed Form 1040-X, Code 971 may be part of the record of your amended return. It does not mean the return was approved or that a refund was sent.

### 3. The IRS recorded a refund check problem

Some Code 971 action codes relate to refund checks. For example, Action Code 011 is linked to a refund check reported as not received.

If this may apply to you, check your refund details and follow the IRS instructions for reporting a missing check.

### 4. An account or administrative update happened

The IRS also uses Code 971 to record administrative actions and account changes. These actions may not require you to send anything or contact the IRS. Seeing Code 971 does not always mean something is wrong with your return.

## What Does “Notice Issued” Mean Next to Code 971?

If your transcript shows “Notice Issued” next to Code 971, it means the IRS recorded that a notice or letter was sent. The notice should explain the action and whether you need to respond.

For example, the notice may:

- Explain a change to your tax return
- Ask for documents to confirm information
- Provide details about an amount you owe
- Explain why your refund is delayed
- Tell you about a decision made

The notice may include a number, such as a CP or LTR number, which helps identify its purpose. Do not assume every Code 971 entry means the same thing; different taxpayers may have Code 971 for different reasons.

## How to Find the Notice Linked to Code 971

If you see Code 971 and want to find out what the IRS sent:

1. **Sign in to your IRS Online Account.** Go to [IRS.gov](https://www.irs.gov/) and complete the identity verification process.
2. **Look for notices and letters.** Check the section with IRS notices, letters, or account messages.
3. **Check your mail.** Some notices are delivered by mail. Check the address associated with your tax account and your physical mail.
4. **Match the notice with your transcript.** Compare the notice date and description with the Code 971 transaction date.
5. **Read the instructions.** Determine whether the notice asks you to send documents, make a payment, correct information, or simply keep the letter.

If you cannot find a notice online or in the mail, contact the IRS through an official channel to ask about the transaction.

## What Is the Difference Between IRS Code 971 and Code 972?

Codes 971 and 972 have different roles:

| Code | General meaning |
| --- | --- |
| 971 | Miscellaneous transaction that records an action based on its action code |
| 972 | Reversal of a Code 971 transaction |

If the IRS records a transaction with Code 971 and later reverses it, Code 972 may appear. A Code 972 entry does not mean your refund was approved or that every account issue is resolved. Compare the dates and descriptions of both transactions to see what changed.

## What Does Code 971 Mean When It Appears With Code 570?

You might see Codes 971 and 570 on the same account transcript:

| Code | General meaning |
| --- | --- |
| 570 | Additional liability pending and/or credit hold |
| 971 | Miscellaneous account action, which may include a notice or other administrative activity |

When both codes appear, the IRS may have placed a hold on a credit while also recording another action, such as sending a notice.

For example:

| Transaction | Date | Amount |
| --- | --- | ---: |
| Additional liability pending and/or credit hold (570) | March 9, 2026 | $0.00 |
| Notice issued (971) | March 18, 2026 | $0.00 |

This is one possible sequence; it does not explain the exact reason for the hold. Check for an IRS notice that explains whether more information is needed or your account is being reviewed.

## Does IRS Code 971 Mean Your Refund Is Delayed?

Not always. Code 971 records a transaction and does not automatically stop a refund. Some actions associated with Code 971 may relate to a refund check, an account change, or other processing that affects when you receive money.

Review the other codes on your transcript:

| Code | General meaning |
| --- | --- |
| 150 | Tax return filed and tax assessed |
| 570 | Additional liability pending and/or credit hold |
| 571 | Reversal of a Code 570 freeze |
| 846 | Refund issued |
| 971 | Miscellaneous transaction |
| 977 | Amended return filed and posted |

If Code 846 appears, it generally means the IRS recorded a refund issuance. Code 971 alone does not say your refund was approved or sent.

You can also check your refund status using the IRS [Where's My Refund?](https://www.irs.gov/wheres-my-refund) tool.

## What Should You Do If Code 971 Appears?

The right action depends on the description associated with Code 971.

### Step 1: Look at the full Account Transcript

Sign in to your IRS Online Account and get the Account Transcript for the tax year you need. Find Code 971 and review transactions before and after it. Check the date, description, amount, and any action code.

If the description says “Notice Issued,” look for the matching notice in your online account or physical mail. If it says an amended return was sent for processing, check your amended return status instead. Not every Code 971 entry requires a response.

### Step 2: Identify the Action Code

Check whether a three-digit Action Code appears with Code 971. It can provide more details about the transaction and help explain what the IRS recorded. If it is unclear, check the related notice or contact the IRS for clarification.

### Step 3: Follow the IRS instructions

If a notice asks for information, send the documents using the method the IRS specifies. If it explains a tax change, compare that change with your return. If it is only an update, keep the notice for your records.

### Step 4: Check your refund status

If you are waiting for a refund, use the IRS [Where's My Refund?](https://www.irs.gov/wheres-my-refund) tool. You generally need your SSN or ITIN, filing status, and exact whole-dollar refund amount.

### Step 5: Contact the IRS if you need help

If you cannot find a notice or do not understand what to do, contact the IRS using the contact information on IRS.gov. Have your transcript and any letters ready so you can explain what you are asking about.

## Frequently Asked Questions About IRS Transcript Code 971

### Is IRS Code 971 bad news?

Not always. Code 971 shows a miscellaneous account action. It might mean a notice was sent, or it may record another action, such as an amended return being sent for processing.

### Does Code 971 mean the IRS sent me a letter?

It might. If the description says “Notice Issued,” it generally means the IRS recorded that a notice or letter was sent. Check your online account and physical mail for more details.

### Does Code 971 mean my tax return is being audited?

No. Code 971 by itself does not mean you are being audited. Check the action code and any IRS letters before drawing conclusions.

### Does Code 971 delay my refund?

Not automatically. Some actions associated with Code 971 may relate to refunds, but the code itself does not mean your refund is delayed. Look for codes such as Code 570 and check your refund status.

### What does Code 971 followed by Code 846 mean?

It could mean that an action was recorded and your refund was issued later. Review the descriptions, dates, and amounts to see what happened.

### What does Code 971 with Action Code 010 mean?

Action Code 010 generally means an amended return or claim was sent to Accounts Management for processing. It does not mean the return was approved.

### What does Code 971 followed by Code 972 mean?

Code 972 generally reverses a Code 971 entry. Review both entries to see what was reversed and whether anything else happened afterward.

### Do I need to call the IRS after seeing Code 971?

Not always. First, check whether the entry says “Notice Issued” or otherwise describes an action. If you received a notice, follow its instructions. Contact the IRS if you still do not understand what is happening.

### How long does Code 971 stay on my transcript?

There is no fixed time. Code 971 records an action and may remain on your transcript. Its presence does not necessarily mean an issue is still ongoing.

### Can Code 971 appear after filing an amended return?

Yes. The IRS may use Code 971 with other codes to show that an amended return was sent to another department. Check your amended return status for updates.

## Conclusion

IRS Transcript Code 971 records actions on your tax account. It is often linked to notices and letters, but it can also show that an amended return was sent for processing or that another account action occurred.

The action code or transaction description helps explain what the IRS actually did. If you see Code 971, review your Account Transcript, check your IRS Online Account for notices, and follow any instructions provided.

Code 971 does not always mean an audit, a refund delay, or a tax problem. Reviewing the transaction along with related codes and official IRS letters gives you a clearer view of your account status.
