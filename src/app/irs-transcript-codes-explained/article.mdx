# IRS Transcript Codes Explained: What Do the Most Common Codes Mean?

If you have downloaded an IRS tax transcript and seen numbers such as **150, 806, 766, 570, 971, or 846**, you may be wondering what they mean. These are IRS transaction codes, which identify activity recorded on your federal tax account.

Reading a transcript can be confusing. You may see codes, dates, and amounts without knowing whether your return has been processed, a refund is delayed, or the IRS needs more information. Common transaction codes can help you follow account activity, but a code alone does not always explain why something happened or what will happen next.

This guide covers common IRS transcript codes, how they may appear on your account, and what to check when you see one.

## What Are IRS Transcript Codes?

IRS transcript codes are three-digit identifiers used by the Internal Revenue Service to describe transactions and other activity recorded on a taxpayer's account. They appear primarily on Tax Account Transcripts and Records of Account.

A code may identify an activity such as:

- Processing a tax return
- Recording federal income tax withholding
- Applying a tax credit
- Posting a payment
- Issuing a refund
- Adjusting a tax account
- Placing or releasing an account hold
- Recording an IRS notice or other administrative action

For example, Code 150 generally means a return transaction was posted, while Code 846 generally indicates that a refund was issued. Code 570 generally indicates an additional account action is pending. A code describes a recorded event; it does not necessarily explain the reason for the event.

## Where Can You Find IRS Transcript Codes?

Not every IRS transcript displays transaction codes. The two most useful documents for reviewing account activity are:

### Tax Account Transcript

A Tax Account Transcript lists transactions recorded on your IRS account. It may show return processing, payments, tax credits, adjustments, refund information, and other account activity.

### Record of Account Transcript

A Record of Account combines information from a tax return with account transaction details. It can help when you want to review both what was reported on your return and later account activity.

You can access available transcripts through your [IRS Individual Online Account](https://www.irs.gov/individuals/get-transcript). The IRS Get Transcript page also explains other request options.

## How to Read IRS Transcript Codes

An account transcript generally presents transaction information in a table. Depending on the transcript, columns may include:

- **Code:** The three-digit transaction identifier
- **Explanation of transaction:** A description of the recorded activity
- **Cycle:** Processing information associated with the transaction
- **Date:** The date associated with the transaction
- **Amount:** The financial amount associated with the transaction

A simplified example might look like this:

| Code | Explanation | Example amount |
| --- | --- | ---: |
| 150 | Tax return filed and tax assessed | $5,000 |
| 806 | Withholding credited | -$6,000 |
| 766 | Tax credit applied | -$500 |
| 846 | Refund issued | $1,500 |

This example is fictional and provided only for illustration. Code 150 generally indicates the return transaction was posted, Code 806 records withholding, Code 766 records a credit, and Code 846 indicates a refund was issued.

Negative amounts commonly represent credits and positive amounts can represent assessments or other debits, but the meaning depends on the transaction and its context. Always read the code, description, date, and amount together. Looking at one code without surrounding entries can lead to incorrect conclusions.

## Most Common IRS Transcript Codes and Their Meanings

These are general explanations of commonly discussed transaction codes. The description shown on your transcript and related IRS correspondence provide important context.

### 1. Code 150 — Tax Return Filed

Code 150 generally indicates that the IRS posted your original return transaction and assessed the associated tax liability. The transcript may also show tax period information, processing dates, and a cycle code.

**Does Code 150 mean my refund is approved?**

Not necessarily. Code 150 indicates a return transaction was posted and tax assessed; it does not independently confirm that a refund has been approved or issued.

### 2. Code 806 — W-2 or 1099 Withholding

Code 806 generally records a credit for income tax withholding reported through information returns, such as W-2s and certain 1099 forms.

For example, if an employer withheld $4,000 in federal income taxes, your transcript may show Code 806 with an amount of **-$4,000**.

**Does Code 806 mean a refund is coming?**

Not by itself. It means withholding was credited to your account. Your final refund depends on your tax liability, other credits, payments, and adjustments.

### 3. Code 766 — Tax Credit Applied

Code 766 generally represents a credit allowance posted to your tax account. Depending on the tax year and circumstances, it may relate to tax credits or other credit transactions.

An amount associated with Code 766 generally reduces your account balance. Whether it contributes to a refund depends on your account balance and other transactions.

### 4. Code 768 — Earned Income Credit

Code 768 generally represents the Earned Income Tax Credit (EITC) credited to a taxpayer's account. The credit amount depends on factors such as earned income, filing status, qualifying children, and applicable income limits.

If you qualify for a refund, the credit may affect the amount you receive. Code 768 alone does not establish your refund amount or payment date.

### 5. Code 570 — Additional Account Action Pending

Code 570 generally indicates that an additional account action is pending and a hold has been placed on the tax module. It is often discussed when a refund has not yet been issued.

Possible circumstances related to account review include return processing issues, income or withholding discrepancies, credit verification, identity verification, or other account matters. Code 570 alone does not identify the reason for the hold.

Review surrounding transcript entries, including any Code 971 transactions, and check whether the IRS has sent you a notice.

**Does Code 570 mean my refund is delayed?**

It can mean a refund cannot proceed while an account action is pending, but the code alone does not say how long the hold will last.

### 6. Code 571 — Hold Released

Code 571 generally indicates that an additional account action associated with a hold has been resolved and the hold has been released. A sequence of Code 570 followed by Code 571 may show that a hold was placed and later released.

**Does Code 571 mean my refund is approved?**

Not automatically. Your account may still need processing before a refund is issued. Look for Code 846 to determine whether the IRS recorded a refund issuance.

### 7. Code 846 — Refund Issued

Code 846 generally indicates that the IRS issued a refund for the amount shown on the transcript. The transcript may also display a date associated with the transaction.

For example, a fictional transcript entry could show Code 846, a refund issuance date, and an amount of $2,500.

**Does Code 846 mean the money is in my bank account?**

Not necessarily. Code 846 indicates the IRS issued the refund; it does not guarantee that your bank has received or posted the funds. Bank processing and delivery times can vary. If you have not received a refund, check your bank account and the IRS refund status service.

### 8. Code 971 — Notice Issued or Other Account Action

Code 971 is associated with different account actions and is commonly connected with an IRS notice or letter. Its exact meaning depends on the accompanying transaction description.

The notice may relate to information requests, return adjustments, refund processing, account verification, or another administrative matter.

**Does Code 971 mean something is wrong with my return?**

Not necessarily. Code 971 is not automatically a problem or audit indicator. Review the description and any IRS letter to understand the specific action.

### 9. Code 290 — Additional Tax Assessed

Code 290 generally represents a tax assessment or an adjustment to the tax liability on your account. It may appear when the IRS changes a return or processes certain account adjustments.

The amount is important. A positive amount may indicate additional tax assessed, while a $0.00 transaction may record an action without increasing your tax liability. Do not assume every Code 290 means you owe additional money; review related transactions and notices.

### 10. Code 291 — Reduction of Assessed Tax

Code 291 generally indicates that previously assessed tax was reduced or removed. If an adjustment creates an overpayment, it may affect your refund or account balance.

### 11. Code 420 — Examination of Tax Return

Code 420 is associated with an examination indicator on a tax account and generally means the return was referred for examination or related review activity. An examination may involve information reported on your return, deductions, credits, or other tax details.

Review any IRS correspondence and follow the instructions provided. The code alone does not tell you the outcome or scope of a review.

### 12. Code 421 — Examination Indicator Reversed

Code 421 generally reverses the examination indicator associated with Code 420. If it appears after Code 420, it may indicate that the examination indicator was removed from the account. The exact status depends on surrounding transactions and IRS correspondence.

### 13. Code 810 — Refund Freeze

Code 810 generally indicates that a refund freeze has been placed on the account. The refund is restricted while the IRS addresses an account matter, but the code does not explain the reason for the freeze.

If you see Code 810:

- Look for related transactions on your transcript.
- Read any IRS notices.
- Follow the instructions the IRS provides.

Do not assume the refund will automatically be released after a specific number of days.

### 14. Code 811 — Refund Freeze Released

Code 811 generally indicates that a previous refund freeze was reversed or released. A sequence of Code 810 followed by Code 811 may indicate the freeze was removed.

Release of a freeze does not automatically mean a refund was issued. Look for Code 846 to confirm that the IRS recorded a refund issuance.

### 15. Code 977 — Amended Return Filed

Code 977 generally indicates that an amended return was posted to the IRS account. Taxpayers generally use Form 1040-X to correct information on a previously filed federal income tax return.

Reasons to amend may include forgetting to report income, claiming an incorrect deduction, entering incorrect tax information, or correcting certain credits. Code 977 does not mean the amendment has been fully processed or accepted. You can check its progress through the IRS [Where's My Amended Return?](https://www.irs.gov/filing/wheres-my-amended-return) service.

### 16. Code 670 — Subsequent Payment

Code 670 generally indicates that a payment was posted to your IRS account after the return transaction. For example, an account transcript may show it after you make a payment toward a balance. Review the transaction amount to see how much was credited.

### 17. Code 276 — Failure-to-Pay Penalty

Code 276 generally represents a penalty for failing to pay taxes by the deadline. Review the amount and related account transactions to understand the charge.

### 18. Code 196 — Interest Assessed

Code 196 indicates that interest was assessed on your tax account. The amount may depend on the balance and how long the tax remained unpaid.

### 19. Code 480 — Offer in Compromise Pending

Code 480 generally indicates that an Offer in Compromise (OIC) was recorded as pending on your account. An OIC may allow eligible taxpayers to settle tax debt for less than the full amount owed. Code 480 does not mean the IRS accepted the proposed settlement.

### 20. Code 976 — Duplicate Return Posted

Code 976 generally indicates that a duplicate return was posted to the account, such as when another return is received for a tax period that already has a return posted. If you do not recognize the transaction, review your account activity and contact the IRS for clarification.

## Common Combinations of IRS Transcript Codes

Individual codes may not tell the whole story. Looking at transactions together can provide more context.

### Code 150 + Code 806 + Code 846

This combination may indicate that the original return transaction was posted, withholding was credited, and the IRS issued a refund.

### Code 570 + Code 971

This combination may indicate that an additional account action is pending and a notice or other action was recorded. Check your mail and IRS online account for correspondence about what the IRS needs or why your account requires processing.

### Code 570 + Code 571

This sequence generally indicates that an additional account action was pending and the associated hold was subsequently released. It does not guarantee that a refund has already been issued.

### Code 810 + Code 811

This combination generally indicates that a refund freeze was placed and later released or reversed. Check for additional transactions to see whether the IRS took further action.

### Code 150 + Code 766 + Code 768 + Code 846

This combination may indicate that the return transaction was posted, applicable credits were recorded, and a refund was issued. The actual refund amount depends on all tax liabilities, credits, payments, and adjustments.

## What Should You Do If You See an IRS Transcript Code?

Seeing a code does not automatically mean there is a problem with your return. The IRS uses many transaction codes, and some are associated with routine account processing.

If you encounter a code:

1. **Identify the transaction code:** Note the three-digit number and its description.
2. **Check the transaction date:** See when the activity was recorded.
3. **Review the amount:** Determine whether it represents a payment, credit, assessment, or another transaction.
4. **Look at surrounding codes:** Earlier and later entries may provide context.
5. **Check IRS correspondence:** Review any letters or notices associated with the transaction.
6. **Contact the IRS if needed:** If you cannot identify the activity or believe there is an error, use an official IRS contact method.

Avoid making decisions based on a single code without reviewing the account information as a whole.

## Frequently Asked Questions About IRS Transcript Codes

### What are common IRS transcript codes?

Commonly encountered codes include 150, 806, 766, 768, 570, 571, 846, and 971. They relate to return processing, withholding, credits, account holds, refund activity, and other account actions.

### What does Code 150 mean on an IRS transcript?

Code 150 generally indicates that the original return transaction was posted and the associated tax liability assessed. It does not automatically mean a refund was approved.

### What does Code 846 mean?

Code 846 generally means the IRS issued a refund. The transaction may include a date and amount, but it does not guarantee that the money has already appeared in your bank account.

### What does Code 570 mean on a tax transcript?

Code 570 generally indicates that an additional account action is pending and a hold was placed on the tax module. The code alone does not explain why.

### What does Code 971 mean?

Code 971 can record different account actions, commonly an IRS notice being issued. Review the accompanying description and any related correspondence.

### What does Code 806 mean?

Code 806 generally represents income tax withholding credited to your account, often from W-2s and certain 1099 forms.

### What does Code 766 mean?

Code 766 generally represents a credit allowance posted to your IRS account. Depending on your circumstances, it may relate to tax credits or other credit transactions.

### What does Code 768 mean?

Code 768 generally represents the Earned Income Credit credited to your tax account. If you qualify for a refund, it may affect the amount.

### Does Code 571 mean my refund is coming?

Code 571 generally indicates that an account action or hold associated with Code 570 was resolved. It does not independently confirm that a refund was issued.

### What is the difference between Codes 810 and 811?

Code 810 generally indicates that a refund freeze was placed on an account. Code 811 generally indicates that the freeze was released or reversed.

### What does Code 290 mean?

Code 290 generally indicates an added tax assessment or an account adjustment. Review the amount and related transactions; a zero-dollar entry does not automatically mean you owe tax.

### What does Code 977 mean?

Code 977 generally indicates that an amended return was posted to your account. It does not necessarily mean the amended return has finished processing.

### Do IRS transcript codes tell me my refund date?

Code 846 generally shows a date associated with the IRS issuing a refund. Other codes, including processing-cycle information, should not be treated as guaranteed refund dates.

### Can IRS transcript codes change?

Yes. New transaction entries may appear as the IRS processes a return, records payments, makes adjustments, or releases account holds.

### Where can I find the IRS transcript code list?

IRS Document 6209 contains descriptions of transaction codes and related processing information.

## Final Thoughts

IRS transcript codes show activity recorded on your federal tax account. Whether you are checking a refund, reviewing payments, or trying to understand an account hold, the codes can help you follow what the IRS has recorded.

Start with common codes such as **150, 806, 766, 768, 570, 571, 846, and 971**, but remember that an individual code may not explain the entire situation. Review dates, amounts, descriptions, surrounding transactions, and any IRS notices.

If you see activity you do not recognize or believe something is wrong, consult official IRS resources or contact the IRS before taking action.
